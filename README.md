# Video Generation Project

Sistema para generar vídeos de avatares hablando usando IA.

## Features

- Generación de vídeos con avatares de IA
- Soporte para texto personalizado
- Síntesis de voz natural
- Exportación en múltiples formatos

## Instalación

```bash
pip install -r requirements.txt
```

## Uso

```bash
python generate_video.py --text "Tu texto aquí" --voice "es-ES" --output video.mp4
```
